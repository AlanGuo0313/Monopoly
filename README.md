# 東京大亨 · TOKYO AFTERGLOW

15 × 15 東京主題 3D 網頁大富翁。原生 JavaScript + Canvas 立體投影 + CSS 3D 骰子，無外部套件、字型或網路資源依賴。

## 開始遊戲

直接以 Chrome / Edge 開啟 index.html 即可離線遊玩。

或雙擊「啟動遊戲.bat」（需要已安裝 Node.js），瀏覽 http://127.0.0.1:4173。終端機保持開啟；關閉終端機即可停止伺服器。

## 新版內容

- 15 × 15：每邊 15 格，共 56 個不重複外圈站點，中央為東京立體街景，不是 225 個可行走格。
- 東京地名：丸之內、秋葉原、上野、淺草、晴空塔、築地、台場、六本木、原宿、澀谷、新宿、池袋等。
- 東京鐵塔、晴空塔、淺草寺風格寺院、鳥居式入口與寶塔的程式化立體模型；為風格化場景，非等比例地理重建。
- 櫻花公園、河道、橋梁、霓虹招牌、窗戶燈光、路燈、遠方富士山與都市剪影。
- 持續行駛的城市電車與計程車、櫻花飄落、河面反光、地標光暈。
- 兩顆 CSS 3D 骰子翻滾、落定顯示實際點數，點數和移動步數一致。
- 購地與落點粒子、棋子跳躍、當前站點提示框、平滑跟隨鏡頭。
- 日景 / 夜景、特效開關、可選擲骰音效。音效預設關閉；特效會尊重系統減少動畫偏好。

## 操作

拖曳：環繞棋盤與調整俯角。
滾輪：縮放。
點土地：檢視地價、租金、持有人與等級。
跟隨視角 / 全景視角：切換鏡頭重心。
重置鏡頭：回復預設角度、倍率與跟隨模式。
擲骰出發 / 空白鍵：你的回合擲骰。

## 規則

一位人類玩家和三位電腦玩家。起始資金 ¥30,000，經過東京車站領取 ¥5,000。

無主土地停留可購買；停留其他人的土地，支付地價 28% × 等級的租金。再次停留自己的土地，資金大於地價且未滿 3 級時，自動花費地價 50% 升級。御神籤可能獲得祭典獎金 ¥1,000 或支出 ¥600；休憩站獲得 ¥300；稅務站支出 ¥800。

現金歸零立即破產，土地回到銀行。最後未破產的玩家獲勝。此為精簡原創規則，沒有抵押、交易或連線多人。

## 存檔

每回合完成後自動存至瀏覽器 localStorage。重新整理時從上次完成的回合繼續。東京版使用 tokyo-monopoly-v2，與原版 island-monopoly-v1 分開，保留原版存檔。直接開檔與本機伺服器使用不同存檔。

## 跟隨鏡頭修正

跟隨模式以當前玩家的即時 3D 棋子位置為鏡頭中心，包含逐格移動、轉角與跳躍，並採較近的觀看倍率。模型與鏡頭共用同一動畫座標，避免慢速追趕落後。切換玩家或全景時以平滑偏移轉場；拖曳可維持自訂環繞角度。


## 地形遮擋修正

已撤回完整場景自動取景的變更，保留人物跟隨、原本的鏡頭俯角與縮放操作。

renderer.js 使用 WebGL 深度緩衝逐像素判斷表面遮擋，取代以整面平均距離決定先後的方式。所有場景表面每幀都會提交，並停用背面剔除，因此不會因轉向而把地形卸載。Canvas 繼續處理背景、文字與粒子。若 WebGL 不可用，使用細分大面的 Canvas 備援；該備援能減少排序錯誤，但不具備逐像素深度判斷。

已以程式測試驗證深度狀態、投影資料、繪製順序互換後的遮擋計算，以及人物跟隨與遊戲規則。尚未完成真實瀏覽器的視覺驗證。

## 主玩家視角與效能更新

視角選單提供：跟隨當前玩家、固定主玩家、全景。固定主玩家始終鎖定索引 0 的奶龍，即使其他玩家正在行動也不切換目標；拖曳、縮放與重置鏡頭仍可使用。

world-renderer.js 將靜態街景的世界座標只上傳一次，鏡頭旋轉與透視交由 GPU uniform 計算，每幀以靜態與動態兩次批次繪製完成場景。舊的投影式 WebGL 與 Canvas 備援保留。逐像素深度測試及完整幾何仍保留，沒有靠方向剔除讓後方地形消失。

右上角顯示實際 requestAnimationFrame 的每秒幀數。畫面固定依螢幕的 devicePixelRatio 以原生解析度繪製，不因 FPS 降低而自動縮小解析度。WebGL 保留反鋸齒並請求高效能 GPU 偏好；實際顯示卡由瀏覽器與作業系統決定。土地點選座標會使用當前像素倍率。

測試確認靜態 GPU 緩衝重用、動態緩衝重用、兩次批次繪製、日夜快取、主玩家鏡頭不被 AI 回合切走，以及原有規則。起始場景的 CPU 投影呼叫由 93,290 次降到 693 次；此為程式路徑測試，不是實際瀏覽器 FPS 或 GPU 效能量測。

## 手機縮放

手機可用雙指張開放大、捏合縮小，單指拖曳旋轉。觸控裝置另提供右下角「＋／−」按鈕，縮放範圍 0.55–2.2 倍。雙指操作不會觸發土地點選；手指抬起、取消觸控或系統中斷後會重新設定手勢基準，避免角度跳動。桌機滾輪與重置鏡頭維持原有操作。

已測試雙指縮放、倍率邊界、縮放後單指旋轉、單指點選、取消觸控、多指切換與按鈕。尚未完成實際手機觸控驗證。
