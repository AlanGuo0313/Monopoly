# 東京大亨 · TOKYO AFTERGLOW

15 × 15 東京主題 3D 網頁大富翁。原生 JavaScript + Canvas 立體投影 + CSS 3D 骰子，無外部套件、字型或網路資源依賴。

## 開始遊戲

直接以 Chrome / Edge 開啟 index.html 即可離線遊玩。

起始頁提供「開始遊戲」、「皮膚選擇」、「遊戲規則」，背景為櫻花樹與飄落花瓣。皮膚包含奶龍、狐狸、波奇塔、白狐狸、柴犬，提供與棋盤共用模型的立體旋轉預覽；按「使用此皮膚」套用到主玩家。選擇另外儲存，不會清除原有遊戲進度。自己的回合且沒有事件進行時，可按「主選單」返回。


## 新版內容

- 五款皮膚使用快取曲面模型。奶龍採較飽滿的腹部與原角色頭身比例；波奇塔採圓潤一體軀幹、側眼與縱向背部把手。狐狸、白狐狸、柴犬為四足體態，包含較長軀幹、自然口鼻、細小眼睛、肩臀與後肢關節；白狐狸冬毛較厚，柴犬保留捲尾。預覽與棋盤共用模型，行走時四肢擺動，尾巴輕微搖動。

- 15 × 15：每邊 15 格，共 56 個不重複外圈站點，中央為東京立體街景，不是 225 個可行走格。
- 東京地名：丸之內、秋葉原、上野、淺草、晴空塔、築地、台場、六本木、原宿、澀谷、新宿、池袋等。
- 東京鐵塔、晴空塔、淺草寺風格寺院、鳥居式入口與寶塔的程式化立體模型；為風格化場景，非等比例地理重建。
- 櫻花公園、河道、橋梁、霓虹招牌、窗戶燈光、路燈、遠方富士山與都市剪影。
- 持續行駛的城市電車與計程車、櫻花飄落、河面反光、地標光暈。
- 兩顆 CSS 3D 骰子翻滾、落定顯示實際點數，點數和移動步數一致。
- 購地與落點粒子、棋子跳躍、當前站點提示框、平滑跟隨鏡頭。
- 日景 / 夜景、特效開關、可選擲骰音效。音效預設關閉；特效會尊重系統減少動畫偏好。

## 操作

拖曳：環繞棋盤與調整俯角。
滾輪：縮放。
點土地：檢視地價、租金、持有人與等級。
跟隨視角 / 全景視角：切換鏡頭重心。
重置鏡頭：回復預設角度、倍率與跟隨模式。
擲骰出發 / 空白鍵：你的回合擲骰。

## 規則

一位人類玩家和三位電腦玩家。起始資金 ¥30,000，經過東京車站領取 ¥5,000。

同一屋主連續持有 3～4 格土地時，這些房屋出現青色光框與環繞光點，每經過一格收取基本租金（地價 × 28% × 等級）的 1.5 倍通行稅；連續 5 格以上改為金色皇冠與較多光點，通行稅為基本租金的 2 倍。特殊站點會中斷連續持地，停留當格不重複收租。關閉特效時保留靜態標記。

走完骰子步數、停在他人土地後，可選擇以地價 × 等級 × 2 收購；先結算當次租稅，收購款全數轉給原屋主，保留房屋等級，且買方交易後須有剩餘現金。路途中不詢問收購；略過即結束回合，電腦玩家也只在落點決定是否收購。收購、破產或土地轉手時，連地加成立即重新計算；沿用原有存檔，不需要重開。

無主土地停留可購買；停留其他人的土地，支付地價 28% × 等級的租金。再次停留自己的土地，資金大於地價且未滿 3 級時，可選擇花費地價 50% 升級，或不升級並結束回合；確認前不扣款。御神籤可能獲得祭典獎金 ¥1,000 或支出 ¥600；休憩站獲得 ¥300；稅務站支出 ¥800。

現金歸零立即破產，土地回到銀行。最後未破產的玩家獲勝。此為精簡原創規則，沒有抵押、交易或連線多人。
